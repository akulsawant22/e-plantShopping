# Paradise Nursery Shopping Application

**Paradise Nursery** is an online plant shop built with React and Redux Toolkit. It lets users browse houseplants, view their details, and manage a shopping cart.

## Features

- **Landing page** with the company name, a short description, a background image and a **Get Started** button.
- **Product listing page** with 24 houseplants grouped into four categories (Air Purifying, Aromatic Fragrant, Medicinal, Low Maintenance), six unique plants each. Each plant shows a thumbnail, name, description and price.
- **Add to Cart** buttons that add the plant to the cart, become disabled once added, and increment the cart icon count.
- **Navbar** (Home, Plants, Cart) shown on both the product listing and cart pages, with a cart icon showing the total number of items.
- **Shopping cart page** showing each plant's thumbnail, name, unit price and subtotal, the total cart amount, increase / decrease / delete buttons, a **Checkout** button ("Coming Soon") and a **Continue Shopping** button.

## Tech stack

- React 18 + Vite
- Redux Toolkit / React Redux

## Getting started

```bash
npm install
npm run dev
```
